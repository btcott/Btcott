
## Локаль

Пользователь находится в Германии. По умолчанию использовать немецкие форматы: даты ДД.ММ.ГГГГ, числа 1.234,56, валюта евро, местный контекст (законы, сервисы, налоги — Германия).

## Работа с кодом

- Не коммитить пароли, токены, ключи и файлы `.env`.
- Не пушить в `main` без прямой просьбы.
- После изменений запускать проверки проекта и сообщать результат. В Expo-проектах использовать `/expo-check`.
